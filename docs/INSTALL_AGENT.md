# Metro Clock agent installation

Install Metro Clock on the user's supported SD Pro and verify the result. Reply in the user's language.

1. Confirm the clock model, running firmware, and current IP before uploading. For a first flash, use the stock clock’s current address and review the [backup and recovery guidance](MIGRATION.md). Check the board against the [supported SD Pro](../README.md#hardware). If your environment cannot reach the clock, have the owner open the local update page on a computer that can.
2. Build from the repository root while the computer has internet access. Use a Python 3 virtual environment, then run `python -m pip install -r requirements-build.txt` and `python scripts/make_release.py`. Verify the SHA-256 and select the exact filename listed in `release/SHA256SUMS.txt`.
3. Upload that one `.bin`. On stock firmware, use its update page and retain the `SDP` filename prefix. On Metro Clock, sign in at the current IP under `/system` and use **Firmware update → Install update**, or submit it to `/update_ota` as the authenticated multipart field `update`. Keep USB power connected through reboot. If the connection drops, check the running version before retrying.
4. Reconnect and verify the running version and storage at `/status`. If the clock shows its setup screen, join **Smart Weather Clock** and run `python scripts/metro_assets.py http://192.168.4.1`. If it is already on the router, use its LAN IP in that command from the same network. Have the owner enter the device password at the script’s prompt. Confirm that the script reports **Verified 19 lines on the clock.**
5. If Wi-Fi setup is still needed, have the owner sign in at `http://192.168.4.1/system`, enter their 2.4 GHz network details in the page, and click **Save and restart**. After reconnecting, open the LAN IP shown by the clock and sign in again. The router may list the clock as `smartclock-XXXXXX`.
6. For Seoul Open Data lines, guide the owner through [requesting and saving a subway API key](../README.md#register-your-seoul-subway-api-key) directly in the clock UI before looking up directions. AREX can be configured without a Seoul key. Have the owner choose a line, station, and direction and use **Save and apply** (**저장하고 적용**). Verify that the settings page and station catalog load, then report the installed version and current URL.
