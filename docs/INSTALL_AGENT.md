# Metro Clock agent installation

Install Metro Clock on the user's supported SD Pro clock and verify it after reboot. Reply in the user's language.

1. Confirm the owner-authorized device and its address before uploading. Use the stock clock’s current address for the first upload. Metro Clock's setup Wi-Fi is **Smart Weather Clock** at `http://192.168.4.1`. If the clock is already on the router, use the address shown by the clock or supplied by the owner. Check the hardware against the [supported SD Pro](../README.md#hardware) and identify the running firmware. Ask if compatibility or the target address is unclear.
2. While the computer has internet access, run `python -m pip install -r requirements-build.txt` and `python scripts/make_release.py` from the repository root. Verify the firmware SHA-256 against `release/SHA256SUMS.txt` and keep the packaged `SDP` filename. The build enforces the `0x7E000` byte OTA limit.
3. On stock SD Pro, use its firmware update page. On Metro Clock, use **Firmware update** at `/system` or the authenticated OTA endpoint. Read the [migration notes](MIGRATION.md) before a first flash. Preserve settings and favorites. Keep power connected through reboot. Ask before formatting storage or switching to a serial flash. If the upload connection drops, check the running version before retrying.
4. Reconnect and verify the running version and storage status. On the setup network, run `python scripts/metro_assets.py http://192.168.4.1`. On the router, use the clock's LAN address in that command. Let the owner enter the device password at the script's prompt or in the clock UI. Enter Wi-Fi passwords in the clock UI.
5. Verify that the Metro settings page and station catalog load. If first-time Wi-Fi setup is still needed, guide the owner to `http://192.168.4.1/system` and use the LAN address shown after it reconnects. Guide the owner through [issuing and saving a personal Seoul subway API key](../README.md#register-your-seoul-subway-api-key) before configuring directions. Report the installed version, current URL, and any step that still needs the owner.
