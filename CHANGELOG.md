# Changelog

Changes to Metro Clock. The device reports its installed version at `/version`.

## Metro Clock 1.3.2-metro10

- Default the Metro clock face and settings page to Korean when no language is saved.

## Metro Clock 1.3.2-metro9

- Restore top-left text alignment after setup, reconnect, and password screens.
- Keep stored labels and arrival numbers inside their LCD regions in both languages.

## Metro Clock 1.3.2-metro8

- Fit English station names and arrival times within the clock display.
- Keep long station, direction, and favorite labels readable on narrow settings pages.

## Metro Clock 1.3.2-metro7

- Save the Seoul API key in its own web form before looking up train directions.

## Metro Clock 1.3.2-metro6 - 2026-11-24

- Added persistent English and Korean selection for the Metro web app and clock face.
- Documented the five favorite slots, optional GPIO4 button, and printable outer shell.
- Restored per-device setup password generation for fresh installs. Existing device passwords are preserved.
- Packaged the firmware, Metro web page, and station catalog for public builds.

Earlier firmware history is available in [SmartClock-OSS](https://github.com/michaeldale/smartclock-oss/blob/b214f30/CHANGELOG.md).
